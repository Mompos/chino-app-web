# 汉字 Paso a Paso — versión web

App para aprender chino simplificado (pinyin, caracteres, composición y escritura) en 10 niveles.

**Abrir:** https://mompos.github.io/chino-app-web/

**Instalar en iPhone:** abre el enlace en **Safari** → botón **Compartir** → **Añadir a pantalla de inicio**. Después funciona sin conexión.

Este repositorio solo contiene la versión publicada; se genera automáticamente desde el proyecto principal con `npm run publicar`.
